### What We Do

- **Conceptual research** — Papers with companion proof-of-concept implementations, each grounded in a concrete use case.
- **Practical development** — Open-source SDKs, developer tooling, and full applications across multiple chains.
- **Whitelabel integration** — Blockchain integration work for teams that want the capability without building it in-house.

### Selected Work

**SDKs & developer tooling**
- [**pyiota**](https://github.com/Consensix-Labs/pyiota) — Python SDK for IOTA Rebased ([`iota-rebased`](https://pypi.org/project/iota-rebased/) on PyPI).
- **Local Testing Starter Packs** — Docker Compose setups for spinning up local nodes: [Bitcoin](https://github.com/Consensix-Labs/Bitcoin-Local-Testing-Starter-Pack), [Ethereum](https://github.com/Consensix-Labs/Ethereum-Local-Testing-Starter-Pack), [IOTA](https://github.com/Consensix-Labs/IOTA-Local-Testing-Starter-Pack), [Solana](https://github.com/Consensix-Labs/Solana-Local-Testing-Starter-Pack).
- [**Multi-chain Address Analyzer**](https://github.com/Consensix-Labs/Multi-chain-Address-Analyzer) — Client-side address inspection across chains.
- [**pygments-lexer-move**](https://github.com/Consensix-Labs/pygments-lexer-move) — Move syntax highlighting for Pygments (Sui / IOTA Rebased).

**Applications**
- [**Vidimus**](https://consensixlabs.com/projects/vidimus/) — A multi-chain document notary. It anchors a file's fingerprint across Bitcoin, Ethereum, Solana, and IOTA, so the file's existence, integrity, and timestamp can be checked independently of any single provider.

**Research + proof of concept**
- [**AI-Verified Software Delivery Escrow**](https://github.com/Consensix-Labs/AI-Verified-Escrow) — AI agents as third-party verifiers in smart contract escrow.
- [**Decentralized Professional Credentials**](https://github.com/Consensix-Labs/Decentralized-Professional-Credentials) — W3C Verifiable Credentials anchored on-chain, with a [selective-disclosure](https://github.com/Consensix-Labs/Decentralized-Professional-Credentials-with-Selective-Disclosure) variant.
- [**Cross-Chain Asset Provenance**](https://github.com/Consensix-Labs/Cross-Chain-Asset-Provenance) — Provenance tracking across chains.
- [**Transparent Charitable Donation Tracking**](https://github.com/Consensix-Labs/Transparent-Charitable-Donation-Tracking) — On-chain fund accountability for charitable giving.

### Our Approach

We start from the problem, not the chain. Each project begins with a concrete use case,
and the technology follows from what it needs — the right chain, the right primitives, and
the smallest sensible on-chain footprint. We prefer working proof-of-concept code to
abstraction, and small verifiable pieces to broad claims.

We work across Ethereum, Bitcoin, IOTA Rebased, and Solana today, but we're not tied to
them. When a project is better served by a chain, language, or tool we haven't used before,
we adopt it. The technology is chosen per project, not fixed in advance.
